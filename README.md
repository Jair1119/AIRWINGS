# Paper Plane Dogfights

crea un videojuego que tratara de batallas aereas de aviones de papel, estara ambientado en casas y patios traseros. sera multijugador con opcion de jugar contra bots, permitiendo además personalizar las aeronaves con diferentes tipos de armas, por ejemplo ligas(estas rebotaran 2 veces), fuegos artificiales, bolitas de papel, y mejoras aerodinámicas desbloqueables mediante progresión en el juego. seran diferentes aviones de papel y carton con estadísticas únicas de velocidad, maniobrabilidad y resistencia al daño. Todo con una estética de estilo artesanal agrega items en los mapas, por ejemplo para restablecer salud, municion mejorada o armas especiales y potenciadores temporales de velocidad o escudos reflectantes.
